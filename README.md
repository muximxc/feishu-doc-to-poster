# 飞书文档一键生成招募海报（feishu-doc-to-poster）

把一篇飞书文档变成一张竖版长图招募海报的豆包 Skill。按模板填好文案，豆包自动完成：读文档 → 抽文案 → 填 HTML 模板 → 渲染 → 质检出图。

支持两种海报类型：
- **课程海报**：用于讲师/社群/志愿者招募
- **活动海报**：用于线下沙龙、活动宣传（含场地照片、嘉宾、时间地点等）

## 飞书文档字段要求

### 通用字段（两种海报都需要）

| 字段 | 必填 | 说明 |
|---|---|---|
| **海报类型** | ✅ | `课程海报` 或 `活动海报` |
| 主标题 | ✅ | 招募主题或活动主题 |
| 副标题/口号 | ✅ | 一句话主张或钩子 |
| 报名方式 | ✅ | 二维码图或报名链接 |
| Logo | ⭕ | 不给用默认 logo |

### 课程海报专属字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 我们在寻找 | ✅ | 4 条以内人选标准 |
| 我们能提供 | ✅ | 4 条以内权益 |
| 愿景/理念 | ⭕ | 品牌价值观 |
| 品牌参考图 | ⭕ | 不给用默认风格 |
| 底部口号 | ⭕ | 可选横幅 |

### 活动海报专属字段

| 字段 | 必填 | 说明 |
|---|---|---|
| 系列名称 | ⭕ | 如「第一期 · 线下沙龙」 |
| 英文标题 | ⭕ | 如「Personal Agent」 |
| 中文标题 | ✅ | 主标题，关键短语会用洋红强调 |
| 钩子文案 | ✅ | 一句话吸引点 |
| 活动形式 | ⭕ | 如「嘉宾分享 → 分桌讨论 → 每桌分享」 |
| 人数限制 | ⭕ | 如「限 30 人」 |
| 嘉宾信息 | ✅ | 包含以下子字段： |
| - 嘉宾姓名 | ✅ | 嘉宾名字 |
| - 社交平台 | ⭕ | 如「𝕏」「微信」 |
| - 社交账号 | ⭕ | 如「@Eejoylove」 |
| - 嘉宾头衔 | ✅ | 2-3 个最抓人的头衔，用加粗标记最强一条 |
| - 分享主题 | ✅ | 嘉宾分享的话题 |
| 时间 | ✅ | 活动时间，如「10.23 周五 19:00-21:00」 |
| 地点 | ✅ | 场地名称和详细地址 |
| 价格信息 | ✅ | 包含以下子字段： |
| - 价格类型 | ⭕ | 如「早鸟」「限时」 |
| - 价格金额 | ✅ | 数字，如「99」 |
| - 价格条件 | ⭕ | 如「前 10 位」 |
| - 原价说明 | ⭕ | 如「原价 149 元 · 含饮品」 |
| 报名截止 | ✅ | 如「10.21 周三截止」 |
| 场地照片 | ✅ | 真实场地照片，突出氛围 |
| 合作方 logo | ⭕ | 联名活动的合作方 logo |
| 情绪短句 | ⭕ | 底部收尾文案，如「在这个时代，一起享受技术的普惠」 |

## 目录结构

```
feishu-doc-to-poster/
├── assets/              # 资源文件
│   ├── logo.png        # 山禾默认 logo
│   ├── venue1.jpg      # 示例场地照片
│   └── *.png           # 其他合作方 logo
├── templates/           # HTML 模板
│   ├── course-poster-template.html    # 课程海报模板（待补充）
│   └── event-poster-template.html     # 活动海报模板
├── examples/            # 示例文件
│   ├── event-poster-example.html      # 活动海报完整示例
│   └── event-poster-example.png       # 活动海报渲染图
├── references/          # 设计规范文档
│   ├── brand-style.md           # 旧版品牌规范（保留）
│   └── design-guidelines.md     # 完整设计规范（含课程/活动）
├── scripts/             # 渲染脚本
│   ├── render.py       # HTML 转 PNG
│   └── autocrop.py     # 自动裁剪白边
├── README.md            # 本文件
└── SKILL.md             # 豆包 Skill 定义
```

## 安装

把仓库放到 `.user_skills/feishu-doc-to-poster/`，替换 `assets/logo.png` 为你的品牌 logo。

## 使用

> 按 feishu-doc-to-poster 出海报：<飞书文档链接>

飞书文档第一行需注明海报类型（课程海报/活动海报），豆包会根据类型使用对应模板。
