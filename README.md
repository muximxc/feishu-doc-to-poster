# 飞书文档一键生成招募海报（feishu-doc-to-poster）

把一篇飞书文档变成一张竖版长图招募海报的豆包 Skill。按模板填好文案，豆包自动完成：读文档 → 抽文案 → 填 HTML 模板 → 渲染 → 质检出图。

## 飞书文档需要覆盖哪些内容

| 区块 | 必填 | 说明 |
|---|---|---|
| 主标题 | ✅ | 招募主题 |
| 副标题/口号 | ✅ | 一句话主张 |
| 我们在寻找 | ✅ | 4 条以内人选标准 |
| 我们能提供 | ✅ | 4 条以内权益 |
| 愿景/理念 | ⭕ | 品牌价值观 |
| 报名方式 | ✅ | 二维码图或报名链接 |
| 品牌参考图 | ⭕ | 不给用默认风格 |
| Logo | ⭕ | 不给用默认 logo |
| 底部口号 | ⭕ | 可选横幅 |

## 安装

把仓库放到 `.user_skills/feishu-doc-to-poster/`，替换 `assets/logo.png`。
